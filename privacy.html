Privacy Policy

App: Clipping Hub
Owner: Luis R
Last updated: November 6, 2026

Clipping Hub is a personal tool used only by Luis R. It is not sold or offered to the public. This policy explains how the app handles Google user data.

What Google data we access

With your consent, Clipping Hub uses Google OAuth and the YouTube Data API v3 with the youtube scope. That lets the app upload videos, update video metadata (including required AI / synthetic-media labels), set privacy status, and read related YouTube channel information needed to publish clips on the owner’s channel.

How we use Google user data

  • To upload and publish short-form clips to the owner’s YouTube channel.
  • To set YouTube labels and privacy settings required for those uploads.
  • To keep a local OAuth refresh token so the owner does not have to sign in for every publish.

Google user data is used only for these purposes. We do not sell Google user data. We do not use Google user data for advertising. We do not share Google user data with third parties except as required to operate the YouTube API connection itself (Google).

How data is stored

OAuth tokens are stored locally on the owner’s Mac under a private config path (readable only by the owner’s account). Video files selected for upload are processed on the owner’s machines and sent to YouTube. We do not operate a public cloud database of Google account contents.

Data sharing

Uploaded videos and related metadata are sent to YouTube / Google as part of normal API use. Aside from that, Google user data from this app is not shared with other companies.

Retention and deletion

Local OAuth tokens are kept until the owner disconnects YouTube in Clipping Hub or revokes access in their Google Account. The owner can revoke access at any time at Google Account permissions. After revoke, local tokens should be deleted from the Mac config folder.

Limited use

Clipping Hub’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy: Luis R, via the Google account that owns the Clipping Hub Cloud project.
